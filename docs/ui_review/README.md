# MOBRA UI review captures

This folder is the review record for the professional interface pass. The
review checklist covers the six requested states:

- Home executive snapshot
- Assessment input and mapping workspace
- Validation center in Standard mode
- Readiness and BRI
- Requirement–Hazard Mapping
- Resources and Contact

The visual states are generated from the checked-in `app.py` and the included
demonstration datasets. No uploaded laboratory data, secrets, local paths, or
deployment credentials are included in this review record. The automated
Streamlit smoke test exercises the Home and Validation states; the same
navigation labels drive the remaining states.
